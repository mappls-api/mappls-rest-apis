# Nearby Record Finder APIs

## Introduction

Nearby Record Finder is a custom search stack of API in which an authorized MapmyIndia API user can insert/update/delete their georeferenced datasets(via either coordinates or eLocs) with defined record types .<br>
In addition to this, a Nearby Search API is also provided to enable the nearby search on the record type as per user provided reference location (either coordinate or MMI place eLocs)

There are following set of APIs under Nearby Record Finder APIs Module.<br>
1. [Add Record API](./add-record-api/) : POST
2. [Update Record API](./update-record-api/) : PUT
3. [Delete Record API](./delete-record-api/) : DELETE
4. [Search Nearby Record API](./search-record-api/) : GET 
5. [Fetch Record Details API](./fetch-record-details-api/) : GET
6. [Bulk Delete Records API](./bulk-delete-records-api/) : POST
7. [Register Schema API](./register-schema-api/) : POST
8. [Update Schema API](./update-schema-api/) : PUT
9. [Get Schema API](./get-schema-api/) : GET
10. [Get List Record API](./list-record-api) : GET
